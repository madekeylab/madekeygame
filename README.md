# 메이드키 (MadeKey)

커스텀 키보드를 조립하고 구매하는 쇼핑몰 웹앱입니다.

## 주요 기능

| 기능 | 화면 | 설명 |
|---|---|---|
| 부품 쇼핑 | `#/shop` | 카테고리·태그(여러 개 동시 선택)·검색·정렬로 부품 찾기 |
| 제품 태깅 | 제품 상세, 쇼핑 | 모든 제품에 태그가 있고, 태그를 누르면 같은 태그 제품만 모아봄 |
| 키보드 조립 | `#/builder` | 케이스 → PCB → 보강판 → 스위치 → 스태빌라이저 → 키캡 순으로 고르면 실시간 미리보기와 호환성 검사, 스위치는 키 개수만큼 자동 계산 |
| 구매 | `#/cart`, `#/checkout` | 빌드 전체를 한 번에 장바구니에 담고 주문 (데모 주문) |
| 키 테스트 | `#/tester` | 60%/65%/75%/TKL 배열에서 눌린 키 표시, 누른 시간, 채터링(30ms 이내 재입력) 감지 |
| 리뷰 모아보기 | `#/reviews` | 전체 리뷰를 카테고리·태그·별점·내용으로 필터, 도움순/최신순 정렬, 리뷰 작성과 "도움돼요" |
| SNS 공유 | 빌드 화면, `#/b?...` | 링크 복사, X·Facebook·Threads 공유, 휴대폰 공유 시트, 인스타그램용 이미지(1080×1350) 저장. 링크를 연 사람은 같은 구성을 보고 바로 담거나 이어서 조립 가능 |

### 호환성 검사 규칙
- 케이스·PCB·보강판의 배열(60/65/75/TKL)이 다르면 **호환 불가**
- 키캡이 해당 배열을 지원하지 않으면 **호환 불가**
- 스태빌라이저 마운트(PCB/판)가 PCB와 다르면 **호환 불가**
- 5핀 스위치 + 3핀 전용 PCB → **주의** (다리 2개 절단 필요)
- 핫스왑이 아닌 PCB → **주의** (납땜 필요)

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm test         # 단위 테스트
npm run build    # dist/ 에 배포용 파일 생성
```

`dist/` 폴더는 어느 정적 호스팅(GitHub Pages, Netlify 등)에 올려도 그대로 동작합니다(해시 라우팅 사용).

## 현재 한계 (데모 단계)
- 서버가 없습니다. 상품·샘플 리뷰는 `src/data/`의 예시 데이터이고, 장바구니·저장한 빌드·내가 쓴 리뷰·주문 내역은 **브라우저(localStorage)에만** 저장됩니다.
- 실제 결제·배송은 없습니다. 실서비스로 가려면 백엔드(상품/주문/회원 DB)와 PG사 결제 연동이 필요합니다.
- 카카오톡 공유는 카카오 개발자 앱 키가 있어야 해서 아직 넣지 않았습니다. (휴대폰에서는 "공유하기" 버튼으로 카카오톡을 고를 수 있습니다.)

## 폴더 구조

```
src/
  data/        상품, 샘플 리뷰, 키보드 배열, 타입
  lib/         호환성·가격(compat), 공유 링크(share), 키 테스트(tester) 로직 + 테스트
  store/       장바구니·빌드·리뷰·주문 상태 (localStorage 저장)
  components/  키보드 SVG 미리보기, 제품 썸네일, 공유 패널, 공통 UI
  pages/       각 화면
```
