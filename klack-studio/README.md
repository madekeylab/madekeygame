# 클랙스튜디오 (klack-studio)

`https://klack-v2.ensol.club` (디자인 시안 v2 · COLORWAY)의 화면과 기능을 그대로 옮긴 Next.js 프로젝트입니다.
여기서부터 기능을 더해 나가기 위한 출발점입니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:3000` 을 엽니다. 배포용은 `npm run build` 후 `npm run start`.

배포 시 환경변수 `NEXT_PUBLIC_SITE_URL` 에 사이트 주소를 넣으면 공유 이미지(og) 경로가 그 주소로 잡힙니다.

## 아직 연결되지 않은 것

화면은 원본과 같지만 눌러도 동작하지 않거나 임시로 처리한 부분입니다.

- **게임랜드 8종과 게임 랭킹** — 게임 화면 틀만 있고 게임 로직은 옮기지 않았습니다.
- **AI 키보드 추천 · 사진으로 찾기** — AI 서버 연결이 필요합니다.
- **회원 로그인 · 가입 · 마이페이지 · 포인트/등급** — 회원 DB가 필요합니다. 로그인 폼은 "준비 중" 안내를 돌려줍니다.
- **주문 조회 · 배송 현황 조회** — 입력 폼만 있습니다.
- **중고마켓 글쓰기, 타건음 자랑, 대회, 스크래치 이벤트** — 저장소가 필요합니다.
- **저장 방식** — 장바구니 · 찜은 브라우저 쿠키에, 주문 · 후기는 서버 메모리에 둡니다(서버를 다시 켜면 주문 · 후기는 사라집니다). 실제 운영 전 DB로 바꿔야 합니다.
- **주문 완료 화면** — 원본 화면을 확인하지 못해 주문서와 같은 부품으로 새로 구성했습니다.
- **결제** — 원본과 같이 무통장 입금 안내만 있고 실제 결제는 없습니다.

## 폴더 구조

```
src/
  app/                 페이지(주소와 폴더가 1:1)와 API
    api/               cart · wish · orders · reviews · search/suggest · track · auth/email
    product/[id]/      상품 상세
    category/[slug]/   카테고리 목록
    brand/[slug]/      브랜드관
    …                  나머지 화면(안내 · 게임 · 이벤트 등)
  components/          화면 부품
    product/           옵션 구성기 · 미리보기 · 후기
    cart/              장바구니 · 주문서
    shop/              목록 공통(필터 · 정렬 · 페이지)
    home/              홈 전용
    devtest/           기기테스트
    widgets/           스위치 비교 · 등급표 · 로그인 폼
  lib/                 규칙과 데이터 접근
    site.ts            브랜드 · 메뉴 · 컬러웨이 · 고객센터 정보
    catalog.ts         상품 조회 · 정렬 · 필터 · 옵션 규칙
    cart-server.ts     장바구니 · 찜(쿠키 저장)
    order.ts           배송비 · 주문서 검증
    orders-server.ts   주문 저장(메모리)
  data/
    products.json      상품 26개(가격 · 스펙 · 옵션 그룹)
    membership.json    회원 등급 · 혜택 표
public/
  css/                 원본 스타일시트(읽기 좋게 풀어 둔 것)
  fonts/ uploads/      글꼴 · 상품 사진
```

## 자주 고칠 곳

- **상품 추가 · 가격 변경** → `src/data/products.json`
- **메뉴 · 브랜드 문구 · 고객센터 번호** → `src/lib/site.ts`
- **입금 계좌 · 무료배송 기준** → `src/lib/order.ts`
- **맨 위 "디자인 시안" 띠 없애기** → `src/app/layout.tsx` 에서 `<CompareBar />` 줄 삭제
- **색 · 모양** → `public/css/` (페이지마다 쓰는 파일은 각 `page.tsx` 의 `<Styles names={…} />` 에 적혀 있습니다)

## 스타일시트에 대해

디자인을 원본과 똑같이 맞추려고 원본 CSS를 그대로 가져와 `public/css/` 에 두었습니다. 파일 이름은 쓰이는 범위로 붙였습니다
(`core*` 전 페이지 공통, `shop*` 쇼핑 화면 공통, `product*` · `game*` · `checkout` 등은 해당 화면 전용).
